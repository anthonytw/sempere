# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, keep discussion about the work, and no harassment.

Report unacceptable behaviour to the maintainer, Anthony Wertz, through a private
GitHub security advisory or a direct message to the maintainer's GitHub account.
